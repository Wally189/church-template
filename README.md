# Church Template

Reusable church website template repository.

This is a management wrapper only. It records the purpose and status of the repository without changing any published website content, appearance or behaviour.

## Status

- **Classification:** Template
- **Current status:** Needs QA review
- **Public showcase status:** Keep public only if clean and understandable; do not pin by default

## Intended use

This repository should act as a reusable starting point for a church or parish-style website.

## What this demonstrates

Potentially demonstrates reusable website structure, public information organisation, editable content patterns and low-maintenance static-site thinking.

## Maintenance notes

Before promotion, check that the template is safe, generic, documented and not confused with a live organisation site.

## Safety notes

Do not include secrets, credentials, private personal material, third-party personal data, or confidential church/community information.
